# Optional Challenge 001 — Position Reporter

This challenge does not contribute to the next release and should be completed on a separate branch.

## Branch

`academy/challenge-001-position-reporter`

## Objective

Press P to print the player's current world position in Godot's Output panel.

Expected example:

`Player position: X=480, Y=360`

## Useful Pieces

- `Key.P`
- `GlobalPosition`
- `GD.Print()`
- `_Input(InputEvent event)` or an input action

Avoid printing continuously while P is held. Prefer a single press.

## Suggested Commit

`academy: add player position reporter`

Completed Developer Academy Challenge 001.

- Added a debug-only position report
- Pressing P prints the player's world position
- No release gameplay systems were changed
