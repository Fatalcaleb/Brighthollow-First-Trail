# Brighthollow Development Roadmap

## 0.1.x — Foundation

- [x] Project starts in Godot 4.7.1 .NET
- [x] Player movement
- [x] Camera follow
- [x] Collision
- [x] Test-town presentation
- [ ] Confirm successful build on the development PC

## 0.2.0 — Interaction and maps

- Dialogue box
- NPC interaction
- Door and map transitions
- One indoor scene
- Pause menu
- Basic game-state service

## 0.3.0 — Creature data

- [x] JSON creature database
- [x] Three starter creatures
- [x] Five wild creatures
- [x] Base stats, types, abilities, descriptions, and move references
- [x] Built-in creature editor and validation

## 0.4.0 — First battles

- One-on-one turn-based battle scene
- Damage calculation
- Move selection
- Victory and defeat
- Experience and leveling

## 0.5.0 — First playable loop

- Wild encounters
- Capturing
- Party management
- Inventory
- Save and load

Later milestones will add trainer battles, the rival, Echo Cave, Arena One, weather, double battles, and story systems.

## Creature Editor — Planned Expansion

- Creature randomizer with configurable elemental categories, stat ranges, rarity, abilities, and personality traits.
- Evolution-family generator supporting one-, two-, and three-stage lines plus creatures that do not evolve.
- Validation rules that keep generated evolution lines internally consistent.
- Sprite assignment by file picker/import.
- Optional original sprite generation based on the creature description, followed by manual approval before saving.
- Front, back, icon, alternate-color, and future animation sprite slots.
- Preview panel and missing-asset warnings.
