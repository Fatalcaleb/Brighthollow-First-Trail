# Brighthollow: First Trail v0.6.0

This single release package contains:

- `Game/` — complete Godot 4.7.1 .NET project
- `Docs/` — release notes, testing checklist, GitHub information, Academy lesson, optional challenge, known issues, and project standards

Open `Game/project.godot` in Godot 4.7.1 .NET, build the C# project, and run it.
