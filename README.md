# Brighthollow: First Trail v0.5.0 — Identity

A Godot 4.7.1 .NET/C# prototype for an original, single-player monster-catching RPG.

## New in v0.5.0

- Title screen
- New Game and Continue
- Player name entry
- Rival name entry
- Four placeholder appearance presets
- Existing-save warning before starting a new game
- Save metadata on the title screen
- Player identity saved across sessions
- Profile information shown in the pause menu

## Controls

- Move: WASD or arrow keys
- Interact: E or Space
- Pause menu: Esc

## Run

1. Open `project.godot` in Godot 4.7.1 .NET.
2. Select **Build > Build Project**.
3. Press F6 or F5.

## Requirements

- Godot 4.7.1 .NET edition
- .NET 8 SDK

All current visuals are original programmatic placeholders. The project has adopted a 32×32 pixel-art standard for future production assets.
