# Changelog

## [0.7.3] - 2026-08-04

### Added
- Copy All Debug Data button on the F3 debug screen.
- Development collision toggle available from the F3 debug screen.
- Solid footprint collision for Mara, the guardian, Professor Alder, and the rival.
- Solid collision for the bed, television, research terminal, and starter table.
- Tree-trunk collision around Mossmere's border trees.

### Changed
- Collision uses object footprints rather than full visual sprite bounds.
- Runtime and Godot project version updated to v0.7.3.
